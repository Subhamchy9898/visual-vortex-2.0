# 🎯 Motivation-Centered Learning Dashboard (Hackathon Prototype)

This project is a **motivation-driven learning dashboard prototype** built during **Visual Vortex 2.0 Hackathon (GDG Rishihood University)**.

The goal was to design an engagement-focused learning system that helps reduce student drop-off by using:

* Progress tracking
* Streak systems
* Gamification
* Better UI/UX

---

## 🧩 Problem Statement

Students often lose consistency while preparing for exams due to:

* Lack of motivation
* No visible progress tracking
* Absence of structured goals
* No reward system

This project aims to solve that using **behavioral design + simple tech implementation**.

## 🚀 Features

### 🔐 Login System

* Basic login simulation
* User session stored using localStorage

### 📊 Progress & Motivation

* Dynamic progress bar
* Motivational messages based on progress
* Personalized dashboard experience

### 📅 Weekly Goals

* Add and track goals
* Mark completion
* Progress auto-updates

### 📆 Habit Tracking

* Weekly calendar
* Daily visit tracking
* Streak calculation

### 🎮 Gamification

* Milestones at 25%, 50%, 100%
* Reward unlocking system
* Interactive reward modals

### ❤️ Engagement Features

* Save and like content
* Quick access cards
* Toast notifications
